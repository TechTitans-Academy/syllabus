## AWS Fundamentals Course Syllabus [Hands-on]

This AWS course covers cloud computing basics and key AWS services like EC2, Lambda, S3, RDS, VPC, Route 53, and CloudWatch. It introduces core concepts such as regions, IAM, networking, storage, monitoring, and load balancing through hands-on learning.

#### 📅 Duration: 4 Weeks (Flexible – Can be adjusted to suit schedule)
#### 🧑‍🏫 Target Audience: Beginners or early cloud learners
#### 🧰 Pre-requisites: Basic understanding of IT / networking concepts is helpful but not mandatory.
---

## Introduction to Cloud and AWS

### 1.1 Introduction to Cloud Computing
- What is Cloud Computing?
- Types of cloud services: IaaS, PaaS, SaaS
- Benefits of Cloud Computing
- Deployment models: Public, Private, Hybrid

### 1.2 Getting Started with AWS
- What is AWS?
- AWS Global Infrastructure: Regions, Availability Zones (AZs)
- AWS Free Tier

### 1.3 IAM (Identity and Access Management)
- Users, Groups, Roles, and Policies
- Access keys vs password authentication
- Best practices (e.g., least privilege)


## 🔹 Compute & Serverless Services

### 2.1 Amazon EC2 (Elastic Compute Cloud)
- Launching an EC2 instance
- EC2 instance types
- Security groups
- SSH access
- Key pairs

### 2.2 Amazon Machine Images (AMIs)
- Creating and using custom AMIs
- Use cases (backup, scale, etc.)

### 2.3 AWS Lambda (Serverless Computing)
- What is Lambda?
- Event-driven architecture
- Creating your first Lambda function
- Integrating Lambda with other services (e.g., S3)


## 🔹 Networking & Storage Services

### 3.1 Networking Concepts
- What is a VPC?
- Subnets (public vs private)
- Route tables
- Internet Gateway (IGW)
- NAT Gateway vs NAT Instance
- Security groups vs NACLs
- Elastic IP

### 3.2 Amazon EBS (Elastic Block Store)
- Attaching volumes to EC2
- EBS volume types
- Backing up with snapshots

### 3.3 Amazon S3 (Simple Storage Service)
- Buckets and objects
- Storage classes
- Versioning
- Lifecycle policies
- S3 permissions and bucket policies


## 🔹 Monitoring, Database, DNS, and Load Balancing

### 4.1 Monitoring with Amazon CloudWatch
- Metrics and dashboards
- Creating alarms
- Logs and log groups

### 4.2 Amazon RDS (Relational Database Service)
- Creating a database instance
- Supported engines (MySQL, PostgreSQL, etc.)
- Backups and snapshots
- Multi-AZ and Read Replicas

### 4.3 Amazon Route 53
- Introduction to DNS
- Hosted zones and records
- Routing policies (simple, failover, latency-based)

### 4.4 Load Balancing
- Introduction to Elastic Load Balancer (ELB)
- Types of ELBs: ALB, NLB, CLB
- Health checks
- Auto Scaling overview


## ✅ Capstone Project (Optional)

**Deploy a 2-tier web application**:
- Use EC2 for web server
- RDS for database
- S3 for static content
- Use a Load Balancer
- Monitor using CloudWatch
- Secure using VPC and IAM

- Hands-on exercises after each module
- Final quiz or mini-project
